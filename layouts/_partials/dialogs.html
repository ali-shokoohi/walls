Learn by trying.

You play the owner of a shared AI bot. You do not need to know Linux, write code, or set up a server. Choose an answer, check it, and see why it works—or what you missed.

There are no lives, timers, or penalties for a wrong answer. Use hints freely. Multi-select missions require exactly the safe choices. In the ordering mission, tap steps in order; tap again to remove one, or use Clear selection to start over.

Take a break anytime. Your answers, feedback, and completed missions are saved in this browser when storage is available. Choose Save & pause to return to the welcome screen. Mission trail lets you revisit unlocked lessons.

Each completed mission awards 100 learning points once. Progress is not sent anywhere. Use ‘Reset progress’ to remove it.

Teaching model, not a security audit: this game simplifies the supplied Hardening a Shared Hermes Agent on Telegram PDF, final edition 28 October 2026. Completing it does not configure, verify, or secure any real system.
